# MINISPEC — shared 순수 유틸

## 0. 이 문서가 다루는 것

`shared/privacy.py`·`shared/factcheck.py`·`shared/money.py`의 함수 6개. 클래스 명세 [[JSD-DOM-002]] 4.14를 함수 안쪽까지 내린 것이다. 이름 가리기와 수치 후검증은 여러 도메인이 같은 규칙을 써야 하므로 한곳에 둔다.

**순수 함수다.** DB·네트워크·시계를 쓰지 않고 아무것도 import하지 않는다(표준 라이브러리 `re`·`math` 말고). 같은 입력이면 같은 출력이다.

형식은 [[JSD-MS-001]]과 같다.

**표기** — `→` 반환·결과, `if 조건 → 결과 · else → 결과` 분기.

## 2. 함수

#### privacy.person_labels 개인 이름 → 개인 A · 개인 B

**시그니처** `person_labels(names: list[str]) -> dict[str, str]`

근거: [[JSD-API-002]] 1.3 · [[JSD-MS-003#RegistryService.holder_names]]

**처리** 받은 순서대로 처음 나온 이름에 `개인 A`, 다음 새 이름에 `개인 B` … `개인 Z`, 그 뒤는 `개인 AA`. 같은 이름(공백 제거 비교)은 같은 라벨. 빈 문자열은 건너뛴다 → `{이름: 라벨}`

**테스트 관점** `["이서연", "김민수", "이서연"]` → A·B · `"이 서연"`과 `"이서연"`은 같은 라벨 · 27번째 → `개인 AA`

---

#### privacy.mask_text 문장 속 이름·주민번호·번지·동호수 가리기

**시그니처** `mask_text(text: str | None, names: list[str]) -> str | None`

근거: [[JSD-PRD-001#N1]] · [[JSD-MS-001#ReviewService.record]] · [[JSD-MS-008#ReportService.shareable]]

**처리**
1. if `text` None → None
2. 이름 — `labels = person_labels(names)` · 긴 이름부터 문장 안 모든 등장을 라벨로 바꾼다. 이름 글자 사이 공백 하나까지 허용해 찾는다(`이 서연`)
3. 주민번호 형태 — `\d{6}\s*-\s*[\d*]{7}` → 지운다
4. 번지 — `\d{1,5}(-\d{1,5})?\s*번지` 와 앞뒤가 숫자·하이픈이 아닌 `\d{1,5}-\d{1,5}` → 지운다(날짜 `2026-07-18`은 세 토막이라 걸리지 않는다)
5. 동·호수 — `제?\s*\d{1,4}\s*동\s*제?\s*\d{1,4}\s*호`, `제?\s*\d{1,4}\s*호`, `제\s*\d{1,3}\s*층` → 지운다
6. 연속 공백 한 칸 → 앞뒤 공백 제거 → 결과

**테스트 관점** `"소유자 이서연 910814-*******"` + 이름 → `"소유자 개인 A"` · `"화곡동 123-4 해피빌 301호"` → `"화곡동 해피빌"` · `"2026-07-18 접수"`는 그대로 · 이름 목록이 비면 이름은 두고 숫자만 · `"5억 5천"`은 그대로

#### privacy.short_region 주소 → 시도·시군구·동

**시그니처** `short_region(address: str | None) -> str | None`

근거: [[JSD-API-002]] 1.3 · [[JSD-MS-004#service_parse.read_property]] · [[JSD-MS-005]] 3장 최우선변제금 지역

**처리**
1. if 비었음 → None
2. 공백으로 나눈다. 첫 낱말(시도)을 줄인다 — `서울특별시` → `서울` · `부산광역시` → `부산`(광역시 모두 같은 방식) · `세종특별자치시` → `세종` · `경기도` → `경기` · `강원특별자치도` → `강원` · `충청북도` → `충북` · `충청남도` → `충남` · `전북특별자치도` → `전북` · `전라남도` → `전남` · `경상북도` → `경북` · `경상남도` → `경남` · `제주특별자치도` → `제주`
3. 뒤 낱말은 끝이 `동` `읍` `면` `가`인 첫 낱말(법정동)까지 붙인다. 숫자로 시작하는 낱말에서 멈춘다
4. → `"서울 노원구 상계동"`

**테스트 관점** `서울특별시 노원구 상계동 715` → `서울 노원구 상계동` · `경기도 부천시 원미구 심곡동 55-1` → `경기 부천시 원미구 심곡동` · 동이 없는 주소 → 시군구까지

#### factcheck.amounts 문장 속 금액을 만원 정수로

**시그니처** `amounts(text: str) -> set[int]`

근거: [[JSD-MS-002#service_agent.check_stated]] · [[JSD-UC-001#UC-A1]] 7

**처리** 쉼표를 뺀 문장에서 아래를 모두 찾아 만원 정수로
- `(\d+(\.\d+)?)\s*억(\s*(\d+)\s*천)?(\s*(\d+)\s*만)?` → `억×10000 + 천×1000 + 만` (`2.1억` → 21000 · `5억 5천` → 55000 · `2억 1000만` → 21000)
- `(\d+)\s*천\s*만` → `×1000` (`8천만` → 8000)
- `(\d+)\s*만\s*원?` → 그대로 (`8000만원` → 8000)
- `금?\s*(\d{5,})\s*원` → `÷10000` 버림 (`금210000000원` → 21000)
- 한 금액이 두 규칙에 걸리면 앞 규칙만

**테스트 관점** 위 예 각각 · `"보증금 1억 8천이에요"` → {18000} · `"3호실"` → 빈 집합 · `"2026년"` → 빈 집합

---

#### factcheck.contradicts 문장 속 금액·비율·등급어가 허용 값과 다른지

**시그니처** `contradicts(text: str, allowed_manwon: set[int], allowed_ratios: set[float], grade: GradeLevel | None) -> bool`

근거: [[JSD-PRD-001#R10]] · [[JSD-MS-002#service_agent.say]] · [[JSD-MS-008#ReportService.write]]

**처리**
1. 금액 — `amounts(text)`의 값마다 `allowed_manwon` 중 `|a − b| ≤ max(b × 0.05, 100)`인 `b`가 없으면 → True. 표기 반올림(`2.1억`)을 받기 위한 허용 폭이다
2. 비율 — `(\d+(\.\d+)?)\s*%`마다 `r/100`과 `allowed_ratios` 중 차이 0.01 이하인 값이 없으면 → True
3. 등급어 — `위험합니다` `위험 등급` `위험으로 판정` → danger · `주의가 필요합니다` `주의 등급` → caution · `안전합니다` `안전 등급` → safe. 찾았는데 `grade`가 None이거나 다르면 → True. 신호 이름 속 낱말(`위험 신호`)은 등급어가 아니다
4. 어느 것도 아니면 → False

**테스트 관점** 허용 {21000}에 `2.1억` → False · `3억` → True · 허용 비율 {0.78}에 `78%` → False, `92%` → True · 등급 caution에 `위험합니다` → True · 등급 미정에 `안전합니다` → True · 숫자 없는 문장 → False

#### money.format_manwon 만원 정수 → 사람이 읽는 금액

**시그니처** `format_manwon(amount: int | None) -> str`

근거: [[JSD-UI-001]] 금액 표기 · [[JSD-MS-002#service_agent.tool_summary]]

**처리** if None → `"-"` · if `amount ≥ 10000` → `amount / 10000`을 소수 첫째 자리로 반올림, `.0`이면 뗀다 + `억` · else → 천 단위 쉼표 + `만원`

**테스트 관점** 21000 → `2.1억` · 20000 → `2억` · 8000 → `8,000만원` · 15555 → `1.6억` · None → `-`

## 3. 미결사항

- [ ] 금액 허용 폭 5%·100만원 — 표기 반올림은 받고 다른 금액은 잡는지 예시 3건의 대화로 확인한다
- [ ] 등급어 목록이 좁으면 모델의 다른 표현("위험한 집입니다")을 놓친다. 넓히면 신호 설명 속 낱말을 잘못 잡는다
- [ ] 이름 가리기는 알려 준 이름만 가린다 — 사용자가 등기부에 없는 다른 사람 이름을 말하면 남는다
